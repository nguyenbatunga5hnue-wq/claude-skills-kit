# Camera Vocabulary — what each choice communicates

Film references for specific techniques: `cinematic-ui/references/data/camera-shots-50.md`.

## Shot sizes

| Term | Frame | Use for |
|---|---|---|
| EWS | Extreme wide, the person is tiny | Isolation, place, passage of time (teacher alone in a schoolyard) |
| WS | Full environment and the whole person | Establishing a scene, geography |
| FS | Head to toe | Body language, walking, entrances |
| MWS | Knees up | Two people interacting, classroom action |
| MS | Waist up | Neutral dialogue |
| MCU | Chest up | Most dialogue, VO reactions |
| CU | Face | Emotion, decisions |
| ECU | Eyes, lips, fingertips | Peak emotion, sensory detail |
| INSERT | An object | Story objects: chalk, red pen, letter, photo |
| OTS | Over the shoulder | Conversation, power balance |
| POV | Through a character's eyes | Memory, discovery |
| 2S / GROUP | Two people / a group | Relationship, class as a community |

## Angles

| Term | Effect |
|---|---|
| eye-level | Neutral, honest; the default for documentary tribute |
| high | Subject seems small or vulnerable; a child's view of the classroom from the teacher's desk |
| low | Authority, admiration; a child looking up at the teacher. Use sparingly, or it reads as propaganda |
| overhead | Pattern, fate, a desk covered in notebooks |
| worm | Extreme low; monumental |
| dutch | Unease. Rarely right for a tribute |
| profile / three-quarter | Profile = contemplation, three-quarter = most flattering for faces |

## Movement

| Term | Effect |
|---|---|
| static | Calm, observation, dignity; the best default for emotional moments |
| pan / tilt | Reveal across or up (tilt up from worn sandals to the face) |
| dolly-in / push-in | Growing realization, intimacy |
| dolly-out | Loneliness, ending, letting go |
| track / truck | Accompany a walking character |
| crane / drone | Scale, opening/closing images. Check drone flight rules near schools |
| handheld | Memory, subjectivity, documentary truth |
| steadicam/gimbal | Floating, dreamlike walk through corridors |
| rack-focus | Shift attention (chalk dust → teacher's face) |
| zoom | 70s/documentary flavor. Avoid on phones |

## Lenses (full-frame equivalent)

| Range | Character |
|---|---|
| 14–24 mm | Space, distortion close up; classrooms look big |
| 28–35 mm | Natural documentary, environmental portraits |
| 50 mm | Human-eye neutral |
| 85–135 mm | Compressed, flattering faces, separation from background |
| Macro | Chalk texture, ink on paper, handwriting |

## Lighting shorthand

- **Window key**: classrooms have big windows. Shoot with the window to the side, not behind.
- **Motivated practical**: desk lamp for night grading (3200K), fluorescent tube for realism (cool, slightly green; correct in grade).
- **Golden hour**: memories, farewells. Schedule exteriors 1 h after sunrise or 1 h before sunset.
- **Negative fill**: a black cloth on one side for shape on flat classroom light.
- **Haze/dust**: chalk dust in a backlight beam is the signature image of the genre. Shoot at 50 fps for slow motion if needed.

## Sound tags

`SYNC` (recorded with picture) · `VO` (voice-over added in post) · `MOS` (no sound recorded) ·
`WT` (wild track: record the sound separately) · `RT` (room tone).
Reference cue IDs from the sound plan: `M1` music, `A3` ambience, `FX7` effect.
